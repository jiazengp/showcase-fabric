# Changelog

Track the latest features, bug fixes, and improvements in Showcase mod releases.

## Version 2.6.0

**Minecraft**: 26.1.2 - 26.3 | Released: September 17, 2026

### 🚀 Major Changes

- Added support for Minecraft 26.3 (Fabric API 0.160.6+26.3, Fabric Loader 0.19.5)
- The same release line still ships 26.1.2 and 26.2 builds

### 🐛 Fixes

- Fixed the "Viewing Content" progress bar continuing to count down after the preview was closed early
- Closing a map preview no longer leaves the viewer flagged as watching, which had been swallowing item use, attacks and entity interactions until the timer expired
- Fixed shared inventory titles showing the raw translation key
- Container and merchant broadcasts no longer claim the content belongs to the player — a shared chest may be one standing in the world, and a merchant belongs to a villager

### 🌍 Translations

- Completed every locale: 21 keys (command duration feedback, viewer countdown, permission errors) were missing from all 15 non-English files and fell back to English
- Fixed swapped placeholders in Spanish, French, Italian, Portuguese, Polish and Russian, which rendered the owner and the shared content the wrong way round
- Reworked the English broadcast copy, which read "Steve I showcased my Hotbar"
- Unified the Chinese copy and aligned the Traditional and Cantonese variants

### 🧪 Testing And Tooling

- Revived the Fabric GameTest suite (13 tests) and wired `runGameTest` into CI, covering bundle and shulker-box slot ordering
- Added a static translation checker to CI that fails on missing keys, placeholder drift, call-site argument mismatches, and broadcast copy slipping out of the third person

### 📦 Requirements

Java 25, Fabric API, Simple GUI • Optional: LuckPerms, PlaceholderAPI

## Version 2.5.0

**Minecraft**: 26.1 - 26.2 | Released: July 9, 2026

### 🚀 Major Changes

- Migrated the mainline branch to Minecraft 26.x with official Mojang mappings
- Added support for Minecraft 26.1.2 and 26.2 builds from the same release line
- Dropped maintenance for pre-26.x versions on this branch

### 🛠️ Compatibility And Fixes

- Fixed shared inventory/container feedback text showing raw translation keys
- Restored the shared container divider to gray stained glass panes
- Fixed empty-slot click handling in shared container views to avoid runtime errors
- Reworked Crafter sharing snapshot logic to prevent slot misalignment and disconnects when opening shares

### 📦 Requirements

Java 25, Fabric API, Simple GUI • Optional: LuckPerms, PlaceholderAPI

## Version 2.4.0

**Minecraft**: 1.21 - 1.21.6

Released: September 26, 2025

### 🚀 New Features

**Extended PlaceholderAPI Support**
- 60+ new placeholders for player statistics and server metrics
- Conditional placeholders with if_xxx_yes_no format
- Permission-based placeholders for dynamic content

**Enhanced Statistics System**
- Redesigned statistics tracking with comprehensive data collection
- Thread-safe statistics cache with performance metrics
- Cross-session persistent storage with automatic recovery
- Enhanced statistics book with 8 detailed categories

**Development Tools**
- Development environment detection for test commands
- Configuration validation and placeholder testing tools
- Automatic restriction of debug features to development builds

### 🔧 Improvements

**Configuration System**
- Automatic backup and recovery for corrupted configs
- Enhanced YAML validation with detailed error reporting
- Optimized configuration reload mechanisms

**Data Storage**
- Automatic error recovery for corrupted data files
- Timestamp-based backup system for data protection
- Improved cross-version compatibility handling

### 🐛 Critical Bug Fixes

**Minecraft 1.21.1 Compatibility**
- Fixed startup crashes due to Mixin method signature incompatibility
- Resolved duplicate file conflicts causing version issues
- Added version-specific code compilation directives

**Stability Improvements**
- Fixed data decoding failures with comprehensive error handling
- Improved GUI cleanup when closing interfaces
- Corrected item icon positioning in chat messages

### 📚 Documentation

- Migrated to new official website (showcase-fabric.vercel.app)
- Added comprehensive PlaceholderAPI integration guide
- Complete developer documentation with API references

### 🔗 Compatibility

- **NEW**: Minecraft 1.21.1 support
- **Continued**: 1.21.2, 1.21.4, 1.21.5, 1.21.6
- **Requirements**: Java 21, Fabric API, Simple GUI
- **Optional**: LuckPerms, PlaceholderAPI

### ⚠️ Important Notes

- Critical compatibility fixes - upgrade recommended
- Automatic data recovery handles corrupted files
- Statistics may need regeneration after update
